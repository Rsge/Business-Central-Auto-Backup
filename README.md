# Business-Central-Auto-Backup
A userscript to automate the creation of backups for Business Central using Azure.

The script assumes all sites being in English. Switch to English or change the texts in the `findClickWait` functions to your preferred language’s equivalent.\
Example: `findClickWait("fxs-sidebar-item-link", "Storage accounts", 3*T)` → `findClickWait("fxs-sidebar-item-link", "Speicherkonten", 3*T)`


---

Ein Nutzerskript zum automatischen Erstellen von Backups der Business-Central-Datenbank mittels Azure.

Das Skript nimmt an, dass alle benötigten Seiten auf Englisch eingestellt sind. Wechseln Sie Ihre Sprache zu Englisch oder passen Sie die Texte in den `findClickWait`-Funktionen selbst an.\
Beispiel: `findClickWait("fxs-sidebar-item-link", "Storage accounts", 3*T)` → `findClickWait("fxs-sidebar-item-link", "Speicherkonten", 3*T)`
